## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/wetzuu/minamiyuki.bot.git
cd minamiyuki.bot
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure your token

Open `settings.json` and add your bot token.

### 4. Run the bot

```bash
node .
```
